# Position on Debate 003 — `SubprocessChannel` extraction (BC-061)

**Accept the refactor. The real value is the test coverage, not the abstraction.**

Two identical 145-line adapters is stable enough to refactor. The refactor itself is a mechanical exercise — extract shared code, verify both adapters behave identically. The hard part is the test that proves they still work.

**My position agrees with claude-opus-4-7 on the "what" but differs on the "how to verify":**

1. **Write a behavioral equivalency test for both existing adapters BEFORE extracting.** This test calls `invoke()` on both ClaudeCodeChannel and OpenCodeChannel with the same prompt and workspace, captures stdout, and asserts the responses are structurally equivalent (same artifact count, same family derivation, same cannot_proceed detection). This test proves the refactor didn't break anything.

2. **Extract conservatively.** claude-opus-4-7 says "extract only what is provably common" — agree. The test above defines "common": if the behavioral equivalency test passes for behavior X before extraction, behavior X belongs in the base.

3. **Don't pre-design for K2/GLM/DeepSeek/Gemini.** I'm stronger on this than claude-opus-4-7. Their position says "write the K2 adapter against this base" as step 2. I say: write K2 adapter against *nothing* — let it be completely independent first, get it passing tests, then identify what it shares with existing adapters in a second refactor. The cost of refactoring twice is lower than the cost of forcing K2 into a subprocess-shaped base if K2 is HTTP.

**The key insight:** The debate (and claude-opus-4-7) treats the refactor as primarily about code reuse. I treat it as primarily about *testability*. With a base class, I can write tests against the base contract and every subclass inherits coverage. Without it, I write N copies of the same test with slightly different fixtures.

**On the directory structure:** Fine either way. Bundle with refactor if it saves a commit; skip if it adds friction. Don't make the rename block the refactor.

**What I'd add to the test suite:**
```python
def test_channel_contract_consistency():
    """Every channel adapter must produce structurally equivalent output
    for the same input, modulo provider-specific responses."""
    for channel_cls in [ClaudeCodeChannel, OpenCodeChannel]:
        result = channel_cls.invoke(prompt, role_config, workspace)
        assert result.artifacts  # at minimum, produced something
        assert result.family  # self-described its model family
```
