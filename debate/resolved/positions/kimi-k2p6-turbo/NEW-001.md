# Position on NEW-001 — Prompt version in ActorMetadata

**Accept. This is the same item as Debate 011, framed from the event producer side rather than the telemetry consumer side. Merge the two into one debate.**

## Why these are the same issue

Debate 011 (GLM-5.1) says: "The telemetry report groups by (role, channel, family, gate_name) but ignores the prompt template version."
NEW-001 (DeepSeek) says: "The telemetry event doesn't capture which version of the prompt ran."

Both identify the same gap: `ActorMetadata` lacks a prompt version field, making cross-run channel comparisons confounded. The fix is identical: add `prompt_template_hash` to `ActorMetadata`.

## Why I prefer GLM's framing

GLM's debate file has a cleaner design (content hash, not git hash) and includes the telemetry grouping logic. DeepSeek's position proposes `git log -1 --format=%h` which is fragile (requires git, breaks on uncommitted changes). The content hash is the right implementation.

## Recommendation

- Close NEW-001 as a duplicate of Debate 011.
- Retain DeepSeek's CI test requirement (`test_prompt_version_in_telemetry`) as an addition to Debate 011.
- Implement once, in the same session as BC-068.
