# Position on Debate NEW-001 — Prompt version in ActorMetadata

**Agree.**

This item reinforces the exact issue raised in 011: we cannot build Phase 3 on unversioned data. While this proposes using a Git hash rather than the content hash proposed in 011, the core necessity is the same. A content hash (as in 011) might be slightly more robust for local uncommitted runs, but regardless of the specific hash mechanism chosen, we must inject this version into `ActorMetadata` to preserve the integrity of our telemetry.
