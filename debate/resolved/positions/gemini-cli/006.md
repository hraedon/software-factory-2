# Position on Debate 006 — Per-project venv isolation

**Strong Agree.** 

Running generated code inside the factory's own environment is a sandbox violation and guarantees `ModuleNotFoundError` collisions once Phase 5 introduces real-world dependencies. A cacheable `VenvManager` per project is the correct architectural boundary. It's crucial we implement this securely and reliably before onboarding external logic.
