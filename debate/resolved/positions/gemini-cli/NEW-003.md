# Position on Debate NEW-003 — Golden run automation

**Agree.**

Manual runbooks do not scale, especially when we start running combinations of models across various prompt versions. Automating this into a single `make golden-run` target ensures that critical steps (like `telemetry --verify`) are never skipped by a human operator. Deferring this strictly until after the GR006a calibration run is a smart, pragmatic choice to avoid premature optimization.
