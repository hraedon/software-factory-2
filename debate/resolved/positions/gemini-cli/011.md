# Position on Debate 011 — Prompt versioning in telemetry

**Strong Agree (Blocker).**

Failing to track prompt template versions makes cross-run comparisons statistically invalid. We cannot make data-driven fleet placement decisions if we cannot distinguish between a model improvement and a prompt improvement. Grouping telemetry by a content hash (`prompt_template_hash`) is a cheap, tamper-evident solution that immediately solves this confounding variable. This must be implemented before Phase 3 fleet comparisons begin.
