# Position on Debate 009 — Event schema evolution

**Agree.** 

Unversioned JSONB drift is a ticking time bomb. While Substrate-level payload schema validation is the ideal long-term goal, implementing a consumer-level schema contract in v2 (`factory/event_schemas.py`) is the most pragmatic immediate step. This should be coordinated with the in-flight BC-070 work to ensure the new `_helpers.py` event shapes comply with the new schemas.
