# Position on Debate 010 — Unbounded event log growth

**Agree.** 

Unbounded JSONB growth in Postgres will eventually degrade query and replay performance. The proposed hot/cold tiering approach (Postgres for hot, compressed JSONL for cold terminal states) is standard practice. For now, tracking `replay_duration_ms` as a telemetry metric is a smart prerequisite before building the archival mechanism. We should monitor this but prioritize more immediate functional blockers.
