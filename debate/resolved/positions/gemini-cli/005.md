# Position on Debate 005 — Test efficacy / mutation testing

**Agree (with shadow-mode caveat).** 

Mechanical AST mutation testing is a brilliant, cheap filter to prevent "test theater." However, instead of immediately enforcing a 0.60 `kill_rate`, we should run the gate in "shadow mode" (compute but do not fail) for a few golden runs. This gives us empirical data to calibrate the threshold and prevents false-rejecting valid early implementations. We need to be data-driven when determining test strictness.
