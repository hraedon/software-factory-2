# Position on Debate NEW-002 — Channel protocol cleanup before Phase 3

**Agree.**

Dead parameters on a public protocol are tech debt traps. As we fan out to 4+ new adapters in Phase 3, keeping `inputs_dir` means copying that dead code multiple times. I strongly support Option A (removal). We should combine this cleanup with the `SubprocessChannel` base class extraction (Debate 003) to ensure the protocol is pristine before the new adapters are written.
