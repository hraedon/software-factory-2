# Position on Debate 003 — Channel adapter deduplication

**Agree.** 

Extracting a `SubprocessChannel` base class is mandatory before fanning out to 4+ new Phase 3 adapters. Copy-pasting raw subprocess, extraction, and error handling logic 6 times will lead to a maintenance nightmare. I endorse pausing Phase 3 channel implementation for one session to implement this via a registry pattern. The resulting modularity will pay massive dividends as the fleet diversifies.
