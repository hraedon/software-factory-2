# Position on Debate 008 — Golden-run fixture representativeness

**Agree.** 

Curated, self-contained fixtures give us a false sense of security. Before declaring Phase 2 completely de-risked, we must run an "adversarial" fixture that requires multi-module state, database/filesystem I/O, and UI interactions. It is better to fail early here than to fail expensively on the first real Phase 5 workload. We must embrace complexity in testing.
