## Gaps to flag

- **`_clean_stale_project_venv` runs during gate setup** (`src/factory/venv.py:93`) — if cleanup fails partway, the `.gate_tools_removed` marker prevents retry, leaving a partially-cleaned project venv. Should catch exceptions and skip writing the marker on failure.

- **`output_extraction.py:_CODE_FENCE_PATTERN`** (`src/factory/output_extraction.py:9`) — the regex `\`\`\`(?:\w+)?\s*\n(.*?)\`\`\`` matches any language tag but captures content as if it's Python. A model that outputs `\`\`\`typescript\n...` will have that content extracted as the artifact. The python-fence-first logic mitigates this, but the fallback any-fence extraction is language-agnostic.

- **The `_run_ruff` tempdir change means ruff results reflect the modified file** (`src/factory/gate.py:708`) — ruff checks the *fixed* artifact, not the original. This is intentional (BC-114), but it means a codebase with an unfixable ruff error that also has fixable errors will pass ruff on the fixable ones and fail on the unfixable one — but the original artifact is untouched. Previous behavior modified the artifact in-place, which was a bug, but it meant subsequent inner gate retries would see a partially-fixed file. Now inner gate retries see the original unfixed file each time. This is more correct but may increase retry count for artifacts with both fixable and unfixable lint issues.
