## Gaps to flag

- **`.factory/logs/` is untracked by git.** The GR-039 logs at `.factory/logs/gr039/` are the forensic record but they're not in version control. If the workspace is cleaned, they're gone. Consider committing logs alongside golden-run configs.
- **`event_schema_unknown_fields: class=SubmitPayload fields=['custom_fields_update']`** appears 13 times in GR-039 telemetry output. This warning indicates the SubmitPayload schema doesn't know about `custom_fields_update`, which was added by BC-185 (transition_fields/routing_fields split). The field works at runtime but the schema validation is noisy.
- **BC-195's `unshare` check is per-process, not per-session.** The `_unshare_available` global is set once and cached. If the environment changes mid-run (e.g., unshare becomes unavailable), the cache is stale. Low risk for single-run scenarios but worth noting.
- **No fixture exercises BC-195's network-blocking path in CI.** The test `test_network_request_in_assembled_tree_fails` is conditional on `_check_unshare()` — if unshare isn't available in CI, the assertion is skipped. The test passes locally but may not in restricted containers.
- **AGENTS.md Phase 5 status section is getting long.** It lists 38 golden runs, detailed exit criteria, and multiple sub-items. This is valuable context but is becoming a wall of text. Consider moving golden-run history to a separate file and keeping only the summary in AGENTS.md.
